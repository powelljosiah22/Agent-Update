# EXAMPLE_COURSE_101 — Course Overview Template

Drop your raw PDF syllabi, PowerPoint slide decks (`.pptx`), Word docs (`.docx`), or Excel sheets (`.xlsx`) into any of the `1_*` folders:
- `1_Syllabus_and_Schedule/`
- `1_Lectures_and_Slides/`
- `1_Homework_and_Problems/`
- `1_Exams_and_Reviews/`

The background `brain_daemon.py` (or running `pipeline_parser.py` manually) will automatically convert them into clean Markdown inside `2_Parsed_Markdown/` and index them into ChromaDB so your **Academic Tutor** can search them in under 50ms!
