# Financial Coach — Procedural Memory (`skills.md`)

## 1. Equity & ETF Fundamental + Factor Review Workflow
When evaluating a ticker or ETF for Callie:
1. Call `yfinance` -> `get_ticker_info` and `get_financials` (or `get_fund_holdings` for ETFs).
2. Summarize valuation multiples, balance sheet health, free cash flow, or fund expense ratio in a clean Markdown table.
3. If evaluating long-term factor tilt, compare historical returns against `~/Agents/Financial_Coach/data/F-F_Research_Data_5_Factors_2x3.csv`.
4. Present an objective 3-Layer assessment (Core Thesis Verification, Key Risks, Long-Term Portfolio Fit).
